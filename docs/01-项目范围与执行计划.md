# 01 项目范围与执行计划

## 1. 项目定位

AI Coach Intent Router 一期是**生产级文本意图路由微服务 + 研发后台**。

Runtime 主链路：

```text
用户文本
  -> 加载 Active Config Release
  -> 动态 Prompt Builder
  -> Qwen/OpenAI-compatible Provider
  -> Structured Output
  -> Pydantic/业务校验
  -> Intent JSON
  -> 主系统按 route 进入既有业务
```

研发后台用于：配置、调试、调用观测、Replay/Diff、批量评测和服务状态。

## 2. 一期业务范围

### 必做

- 7 个一级 Route：
  - `training_business`
  - `information_query`
  - `sports_knowledge`
  - `safety`
  - `dialogue_device_control`
  - `social_chat`
  - `unknown`
- 训练业务：一期只要求一级 Route 命中。
- 其他 Route：可输出二级 Intent、Slots、Risk、Clarification。
- 所有一期文本先走 LLM；不实现 Safety 关键词硬路由。
- Prompt 动态组装，业务配置在线维护。
- Runtime/Admin API 分离。
- Provider Attempt 级 Trace。
- 单条调试 repeat 1/3/5。
- Replay/Diff。
- Excel 批量评测与导出。
- MySQL 8 持久化。
- Docker/K8s 上线产物。

### 一期不做

- 语音/多模态/ASR/翻译。
- 确定性 Safety Guard。
- 训练业务缺参追问和训练计划生成。
- Redis、MQ、向量库。
- RAG、多 Agent。
- 平台业务 API 真接入。

## 3. 一期不是 Demo 的最低生产要求

- Runtime Contract 有版本边界。
- Provider timeout/retry/concurrency 有上限。
- 每次 Provider 调用可追踪。
- 配置发布生成不可变 Snapshot。
- 多 Pod 配置最终一致。
- 数据库变更可 migration。
- Evaluation 任务重启不丢。
- Admin 入口不暴露给设备/业务网关。
- Secret 不进入 Trace/日志。
- CI 可运行核心测试。
- K8s 具备 readiness/liveness/graceful shutdown/rolling update 基础设置。

## 4. 技术栈

- Vue 3 + TypeScript + Vite + Element Plus
- Python 3.12+ + FastAPI + Pydantic v2
- SQLAlchemy 2.x + Alembic
- MySQL 8
- Qwen / Alibaba Model Studio OpenAI-compatible API
- Docker + Kubernetes

一期不把 LangChain/LangGraph 作为必需依赖。

## 6. 验收核心

- `/api/v1/intent/analyze` 可稳定输出合法 Runtime JSON。
- 同一 request 可通过 request_id/trace_id 追到完整 Provider Attempt。
- 研发可在线修改配置并发布，不改代码。
- 历史 Release 不可变，可复制旧 Snapshot 再发布进行回退。
- 批量评测能完整执行、失败 Case 可跳 Trace、结果可导出。
- Pod 重启后 Release/Trace/Evaluation 数据不丢失，进行中的 Evaluation 能恢复或明确失败。
- 设备/业务入口无法直接访问 `/api/admin/*`。
