# 04 后台页面与交互设计

## 1. 一级菜单

保持 5 个菜单：

1. 单条调试
2. 批量测评
3. 调用观测
4. 配置中心
5. 服务状态

页面目标是研发诊断，不建设通用 LLMOps 平台。

## 2. 单条调试

输入：

- text
- release（默认 Active）
- model config override（可选）
- repeat 1/3/5

结果：

- route / intents / slots / risk
- clarification
- Runtime JSON
- reason_summary/evidence（明确标记 Debug Only）
- 每次执行稳定性分布

调试详情：

- Config Release
- Effective Model Config
- Final Prompt
- Provider Attempts
- Raw Request/Response
- Parsed/Validation
- Timeline
- Token/Latency/Error

## 3. 批量测评

流程：

```text
上传 Excel -> 生成 Dataset -> 创建 Run -> Worker 执行 -> 看指标/FAIL -> Trace -> 导出
```

页面显示：

- Run status/progress
- Overall Route Accuracy
- 一级 Route 混淆矩阵
- Per-route Precision / Recall / F1
- Safety Route Recall
- Secondary Intent Accuracy
- Clarification Trigger Accuracy
- Avg/P95 latency
- Stability
- FAIL/ERROR 筛选
- Run 对比：仅同一 `dataset_hash`；逐 Case 展示 A/B 状态、PASS→FAIL/ERROR 回归、FAIL/ERROR→PASS 改善；repeat>1 时同时展示各 Run 的 repeat 通过数与 Route 分布

## 4. 调用观测

列表字段：时间、request_id、trace_id、source、input、route、model、release、latency、status。

过滤：request_id、关键词、route、intent、model、release、时间、status。

详情：

- Runtime Result
- Config/Model Snapshot
- Final Prompt
- LLM Attempts
- Raw Request/Response
- Parsed/Validation
- Reason/Evidence
- Timeline
- Error

### Replay

- Historical snapshot replay
- Current active release replay
- repeat 1/3/5
- 新建 trace_id，记录 parent_trace_id

### Diff

选择两个 Trace，比较：

- input
- release/hash
- prompt hash/final prompt
- effective model config
- provider metadata
- attempt count/detail
- raw response
- parsed result
- final result

Diff 重点是定位“差异首次出现的位置”，不建设复杂文本审阅平台。

## 5. 配置中心

UI 仍按业务分区：

- Intent
- Slot
- Enum/Alias
- Route
- Prompt Template
- Model Config
- Release

底层 Draft 可以是单个 JSON 文档，不要求每个分区一张数据库表。

操作：编辑、保存 Draft、校验、Prompt Preview、Publish、History、从历史版本创建 Draft。

## 6. 服务状态

轻量显示：

- Service Ready（`/ready`：进程 + DB/基础依赖）
- Runtime Config Ready（Active Release + default Model Config）
- Active Release/version/hash
- 默认 Model Config
- 最近 24h request/error count
- Avg/P95 latency
- Evaluation queue/running count

不建设 Prometheus/Grafana 管理台；平台已有监控可继续采集普通应用日志/指标。
