# AICoach 当前实施计划

## 现在先做什么

先重做配置中心。配置中心通过后，再处理意图识别结果页和调用观测页。

配置中心只维护识别规则。模型地址、API Key、默认模型仍在“模型管理”。

## 配置中心目录

- 意图管理
  - Route 管理
  - Intent 管理
- 参数管理
  - Slot 管理
  - Enum / Alias 管理
- 样例管理
- 提示词管理
- 配置发布

有多个子页面的目录可以展开、收起；只有一个页面时不再套一层目录。

## 每个页面做什么

### Route 管理

决定用户输入先进入哪个一级业务分类。

- 固定显示 7 个 Route。
- Route key 不能修改、删除或禁用。
- 可以修改中文名称和业务描述。
- 显示每个 Route 下有多少个 Intent。

### Intent 管理

管理每个 Route 下的二级意图。

- 按 Route 查看 Intent。
- 新增、编辑、启用或禁用 Intent。
- 配置中文名称、说明和别名。
- 显示该 Intent 被哪些样例使用。

### Slot 管理

定义需要从用户原话中提取什么信息。

- 管理 Slot 名称、说明和类型。
- 每个 Slot 在 Enum / Alias 页面自动建立一个词组父级。
- 字符串类型由 LLM 返回原文值，服务端补齐中文名和 UTF-16 span；父级下最多三个词组作为 Prompt 示例，不限制输出。
- 枚举类型由程序匹配标准值、显示名称或别名，完整词典不进入 Prompt。

### Enum / Alias 管理

把不同说法转换为统一标准值。

- 按 Slot 父级管理 LLM 参考示例或程序匹配词典。
- 文本型 Slot 管理参考示例和相近说法；枚举型 Slot 管理标准值、显示名称和程序匹配别名。
- 显示父级对应的 Slot 和类型。
- 例如：膝、膝盖、膝关节统一为 knee。

### 样例管理

用真实句子告诉模型应该识别成什么。

- 填写用户输入示例。
- 选择期望 Route。
- 可选期望 Intent。
- Intent 只能选择当前 Route 下的 Intent。
- 支持启用和禁用。
- 使用结构化表格、搜索和筛选，不直接编辑 JSON。
- Route 级样例辅助一级分类；Intent 级样例辅助二级分类。

### 提示词管理

管理模型识别时使用的总体说明和规则。

- 编辑 System Prompt。
- 逐条编辑规则。
- 可以统一开启或关闭“在最终 Prompt 中使用典型说法”；关闭不会删除样例数据。
- 输入一句测试文本，查看最终生成的 Prompt。
- 页面说明最终 Prompt 会自动带上 Route、Intent、文本 Slot 和可选样例；枚举词典由程序使用，不进入 Prompt。

### 配置发布

把编辑中的配置正式发布。

- 显示 Draft 是否已保存、是否校验通过。
- 显示本次修改了哪些配置。
- 填写发布说明并发布。
- 查看当前生效版本和历史版本。
- 可以从历史版本重新创建 Draft。
- 业务配置版本与模型选择相互独立；切换默认模型不需要重新发布业务配置。
- 默认不显示数据库 ID、Hash、Fingerprint 或原始 JSON。

## 页面统一要求

- 页面顶部直接说明“这个功能控制什么”。
- 使用表格、表单和 Dialog，不让用户编辑大段 JSON。
- 保存只更新 Draft；只有发布后才影响真实识别。
- 有未保存修改时必须明显提示。
- 校验错误要指出具体页面、记录和字段。
- 不展示 Credential Ref、Version、Hash、Fingerprint、Release ID 等内部字段。

## 开发顺序

1. 整理目录、页面标题和功能说明。
2. 完成 Route、Intent 管理页面。
3. 完成 Slot、Enum / Alias 管理页面。
4. 完成样例管理页面。
5. 完成提示词管理和 Prompt 预览。
6. 完成 Draft 保存、校验和错误定位。
7. 完成配置发布和历史版本。
8. 用户验收配置中心。
9. 完善意图识别结果页。
10. 整理调用观测页。

## 本轮已确认的架构调整

- 不改变 7 个 Route。
- 不改变 IntentResult、Slot、Risk、Clarification。
- Release 只保存业务配置快照，不再绑定模型。
- 模型选择由 `managed_model + runtime_model_state` 独立负责。
- 删除旧 `model_config` 表及其 API、Provider 和运行时兼容路径。
- 不兼容旧历史：迁移时清理旧 Release、Trace、Evaluation 等依赖旧 ModelConfig
  语义的数据；保留业务 Draft 和使用加密凭据的 ManagedModel。
- 迁移不可逆，执行前应由部署方自行确认是否需要数据库备份。
