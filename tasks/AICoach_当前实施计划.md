# AICoach 当前实施计划

## 现在先做什么

先重做配置中心。配置中心通过后，再处理意图识别结果页和调用观测页。

配置中心只维护识别规则。模型地址、API Key、默认模型仍在“模型管理”。

## 配置中心目录

- 意图管理
  - Route 管理
  - Intent 管理
- 参数管理
  - Slot 管理
  - Enum / Alias 管理
- 样例管理
- 提示词管理
- 发布管理

有多个子页面的目录可以展开、收起；只有一个页面时不再套一层目录。

## 每个页面做什么

### Route 管理

决定用户输入先进入哪个一级业务分类。

- 固定显示 7 个 Route。
- Route key 不能修改、删除或禁用。
- 可以修改中文名称和业务描述。
- 显示每个 Route 下有多少个 Intent。

### Intent 管理

管理每个 Route 下的二级意图。

- 按 Route 查看 Intent。
- 新增、编辑、启用或禁用 Intent。
- 配置中文名称、说明和别名。
- 显示该 Intent 被哪些样例使用。

### Slot 管理

定义需要从用户原话中提取什么信息。

- 管理 Slot 名称、说明和类型。
- 字符串类型直接提取原文。
- 枚举类型必须选择一个 Enum Group。

### Enum / Alias 管理

把不同说法转换为统一标准值。

- 管理 Enum Group。
- 管理标准值、显示名称和别名。
- 显示当前 Enum Group 被哪些 Slot 使用。
- 例如：膝、膝盖、膝关节统一为 knee。

### 样例管理

用真实句子告诉模型应该识别成什么。

- 填写用户输入示例。
- 选择期望 Route。
- 可选期望 Intent。
- Intent 只能选择当前 Route 下的 Intent。
- 支持启用和禁用。

### 提示词管理

管理模型识别时使用的总体说明和规则。

- 编辑 System Prompt。
- 逐条编辑规则。
- 输入一句测试文本，查看最终生成的 Prompt。
- 页面说明最终 Prompt 会自动带上 Route、Intent、Slot、Enum 和样例。

### 发布管理

把编辑中的配置正式发布。

- 显示 Draft 是否已保存、是否校验通过。
- 显示本次修改了哪些配置。
- 填写发布说明并发布。
- 查看当前生效版本和历史版本。
- 可以从历史版本重新创建 Draft。

## 页面统一要求

- 页面顶部直接说明“这个功能控制什么”。
- 使用表格、表单和 Dialog，不让用户编辑大段 JSON。
- 保存只更新 Draft；只有发布后才影响真实识别。
- 有未保存修改时必须明显提示。
- 校验错误要指出具体页面、记录和字段。
- 不展示 Credential Ref、Version、Hash、Fingerprint、Release ID 等内部字段。

## 开发顺序

1. 整理目录、页面标题和功能说明。
2. 完成 Route、Intent 管理页面。
3. 完成 Slot、Enum / Alias 管理页面。
4. 完成样例管理页面。
5. 完成提示词管理和 Prompt 预览。
6. 完成 Draft 保存、校验和错误定位。
7. 完成发布管理和历史版本。
8. 用户验收配置中心。
9. 完善意图识别结果页。
10. 整理调用观测页。
