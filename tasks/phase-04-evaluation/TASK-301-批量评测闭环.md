# TASK-301 批量评测闭环

原方案由用户指定为参考，当前实施以 V2 项目现状和本轮确认需求为准：

1. 问题—标准答案 Excel 模板和页面编辑。
2. 单意图、复合意图、动作参数和依赖的精确检查。
3. 可选模型评审自然语言标准，人工复核保留历史。
4. MySQL 持久任务与独立 Worker，分别冻结业务 Release 和 ManagedModel；支持恢复、取消和幂等结果。
5. 明确的最终通过率，执行错误保留在分母；待复核、未执行时不冒充最终结论。
6. badcase 筛选、对照原因、导出、新任务复测。
7. 同集对比、附加重复稳定性、关键用例与阈值验收。
